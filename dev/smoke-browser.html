Browser smoke test (ImageBitmap transfer)

This page exercises browser-specific code paths:

  • getUserMedia video stream
  • createImageBitmap + transferable postMessage
  • Worker detection events (ar:workerReady, ar:markerFound, ar:markerUpdated, ar:markerLost)

Open devtools console to observe events. NOTE: This is not an example for production usage; see examples/simple-marker for a guided demo. For secure contexts (camera access), use http(s) or localhost. To load patterns you would still call plugin.loadMarker(), omitted here for brevity. Version can be logged via plugin.version.
